# ductile-systems

A collection of crates used to help build more resilient systems and reshape what's possible in the
Rust ecosystem.

```
ductile, adj.
1. of a metal : capable of being drawn out into wire or thread
2. easily led or influenced
3. capable of being fashioned into a new form
```

## Crates

- ductile-systems-testing: testing utilities, types, etc. used to make working with Rust tests
  an enjoyable experience
